# NavAssist test checklist (5 minutes)

Install the APK, then tick each line. If something fails, send me the line number and what you saw.

1. [ ] Home: the hero shows the title; tap **Start floating assistant**; the orb appears.
2. [ ] Setup: overlay, accessibility (Settings > Setup) and permissions show **Done**.
3. [ ] Tap the orb: the menu opens. Swipe it sideways: page 2 appears.
4. [ ] **Home** button opens the launcher. **Back** goes back. **Notifications** and **Quick panel** open.
5. [ ] **Recents:** the system recent apps screen OR the NavAssist **Recent apps** panel appears (Settings > Test > Test Recents tells you which).
6. [ ] **Mixer:** play a YouTube video; drag **Media** down: the sound gets quieter. If not, tap **Open system volume panel** and tell me if that works.
7. [ ] **Vol -** lowers the YouTube volume (the system volume bar shows).
8. [ ] Long-press the orb: it hides for about 15 seconds, then returns.
9. [ ] **Screenshot** button: the screenshot does not contain the orb.
10. [ ] **Recording:** record 5 seconds; it appears in Recording > Library; Play works.
11. [ ] **AI:** add a key (Tools > AI), ask a question by typing, then by voice.
12. [ ] Design > Theme > **Light**: the menu, mixer and Recent apps panel turn light with readable text.
13. [ ] Cleaning: the gauge shows; **Clear** cache works.
14. [ ] Connections: Wi-Fi and Bluetooth show On/Off and **open** their panels.
